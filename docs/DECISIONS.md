# DECISIONS — журнал решений

Записываем только то, что пользователь явно подтвердил. Предложения и вопросы держим отдельно.

## Подтверждённые решения

### Работа с Git
- `main` — основная ветка; напрямую её не изменять.
- Разработку вести в feature-ветках.
- Для «Кривого» используется `feature/krivoy-anomaly`.

### Разделение NPC и аномалии
- Обычные посетители остаются на общей логике `npc.gd`.
- Для «Кривого» планируются отдельные `krivoy.gd` и `krivoy.tscn`.

### Переключение света
- Свет переключается нажатием на интерактивную кнопку `scenes/desk/button.tscn`.
- Каждое нажатие меняет состояние света на противоположное.
- Кнопка доступна независимо от того, идёт ли атака аномалии.
- Переключение клавишей L удаляется; управление светом через клавиатуру не используется.

### Объём механики «Кривого»
- Выключение света нейтрализует «Кривого» только во время его активной атаки.
- ПК и радио пока не отключаются.
- Другие аномалии в рамках этой задачи не добавляются.

### Ранее согласованная основа исхода атаки
- На реакцию игроку отводится примерно 3 секунды.
- Успешное выключение света во время атаки приводит к уходу «Кривого» влево за экран с отдельным звуковым сопровождением.
- Если игрок не успевает — Game Over.

## Открытые вопросы

- Что делает «Кривой», если появляется, когда свет уже выключен?
- Как именно свет влияет на момент проявления и начало атаки при разных исходных состояниях?
- Нужно ли уточнить длительность или визуальные/звуковые эффекты таймера?

## Важное уточнение

Ранее предложенный ассистентом вариант «Кривой появляется в темноте, а игрок должен включить свет, чтобы проявить его и запустить атаку» **не утверждён пользователем**. Не реализовывать его без отдельного согласования.
