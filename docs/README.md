# Студак, Пожалуйста! — документация проекта

Единая точка входа в документацию игры. Документы обновляются по мере согласования решений и реализации.

## Разделы

- [GDD — игровой дизайн](GDD.md): игровые системы, NPC и аномалии.
- [TECHNICAL — техническая архитектура](TECHNICAL.md): сцены, скрипты, связи и технические соглашения.
- [DEVELOPMENT — процесс разработки](DEVELOPMENT.md): ветки Git, порядок работы и проверки.
- [DECISIONS — журнал решений](DECISIONS.md): подтверждённые решения и открытые вопросы.
- [TODO — задачи](TODO.md): текущие задачи и дальнейшие шаги.

## Статусы информации

- **Согласовано** — решение явно подтверждено пользователем.
- **Предложение** — вариант для обсуждения, не считать утверждённым.
- **Не проверено** — сведения требуют сверки с актуальным проектом или запуска в Godot.

## Главное правило

Документация не даёт разрешения на изменение кода. Сначала обсуждаем и фиксируем план, затем получаем отдельное явное подтверждение на реализацию. Изменения вносятся в рабочую feature-ветку, не напрямую в `main`.
